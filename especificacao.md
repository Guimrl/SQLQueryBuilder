Objetivo
Criar um gerador de queries SQL a partir de uma tabela de banco de dados relacional.

Especificações Funcionais
O programa precisa atender aos seguintes requisitos funcionais:
● Ser fácil de operar;
● Permitir que o usuário especifique quais colunas serão retornadas (SELECT);
● Permitir que o usuário especifique as condições da busca (WHERE);
● Permitir que o usuário especifique as colunas para ordenação (ORDER BY);

Sinta-se à vontade para implementar recursos adicionais, e utilizar o SGBD de sua preferência.

Especificações Técnicas
O programa precisa ser construído com uma das seguintes stacks de desenvolvimento:
Frontend Backend
C# Windows Forms C# Windows Forms
ASP.NET Web Forms ASP.NET Web Forms
C# Windows Forms .NET Web API
HTML, CSS e JS puros (sem frameworks) .NET Web API

Especificações de Entrega
O código fonte do programa deve ser disponibilizado em um repositório do Github com a
documentação do programa destinada a usuários finais.
